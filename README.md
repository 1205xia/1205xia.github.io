# 夏瑶雯个人作品集

公开网页：[https://1205xia.github.io/](https://1205xia.github.io/)

## 主要文件
- `src/main.tsx`：React 页面、栏目切换、入口交互和内容
- `src/styles.css`：布局、响应式样式和动画
- `public/microvisuals-bg.mp4`：内页动态背景
- `public/heartbeat.json`：Lottie 动效资源
- `SKILL-web-optimization.md`：给其他 AI 的完整制作规范和提问流程
- `package.json`：开发与构建命令

## 本地运行
```bash
npm install
npm run dev
```

生产构建：`npm run build`

后续维护时，先读取 `SKILL-web-optimization.md`，先询问个人资料、栏目、项目、视觉和动画需求，确认后再修改。公开发布前不得提交本机地址、临时文件、密钥或未授权资料。
